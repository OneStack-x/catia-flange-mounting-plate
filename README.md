# catia-flange-mounting-plate
# CATIA Flanged Mounting Bracket (3D & 2D CAD)

This repository contains the parametric 3D CAD model and 2D engineering drawing for a **Flanged Mounting Plate / Base Bracket** designed in **Dassault Systèmes CATIA V5**[cite: 4].



## ⚙️ Design Highlights & Features
* **Central Cylindrical Hub:** Features an 8-hole circular bolt pattern (`8x Ø15 mm` on a `106 mm PCD`)[cite: 3, 4].
* **Slotted Base Plate:** Includes 4 corner mounting holes and U-shaped alignment/clearance slots on both ends[cite: 4].
* **Parametric Modeling:** Built using standard Part Design features (Pad, Pocket, Hole, and Circular Pattern).

## 📁 Repository Contents
* **`3D_Model/`**: Native CATIA part file (`.CATPart`) and universal `.stp` format.
* **`2D_Drawing/`**: Technical blueprint with dimensions and tolerances (`.CATDrawing`).
* **`Renders/`**: High-resolution preview images of the model.

## 🛠️ Software Used
* **CAD Software:** Dassault Systèmes CATIA V5
* **Workbenches:** Sketcher, Part Design, Interactive Drafting

## 📥 How to Open
1. Download or clone the repository.
2. Open **CATIA V5**.
3. Load `3D_Model/flange_plate.CATPart` to inspect the feature tree or modify dimensions.
